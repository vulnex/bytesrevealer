# Security Policy

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

We take the security of Bytes Revealer seriously. If you discover a security vulnerability, please report it privately through GitHub's Security Advisories.

**To report a vulnerability:**

1. Go to https://github.com/vulnex/bytesrevealer/security/advisories/new
2. Provide a detailed description of the vulnerability
3. Include steps to reproduce the issue if possible
4. Do NOT open a public issue for security vulnerabilities

**Response expectations:**

- We will acknowledge your report and begin investigating the issue
- We will keep you informed of our progress
- Once the vulnerability is confirmed and fixed, we will coordinate the public disclosure with you

Thank you for helping keep Bytes Revealer and its users safe!
